# AI 安全智能体项目执行计划

## 1. 项目目标

项目面向题目 `XH-202614`，在深信服分布式 XDR、平台垂域模型和响应联动能力之上，开发一套可研判、可追溯、可约束、可扩展的安全智能体系统。

交付优先级：

1. 稳定完成基础任务：告警研判 Agent 闭环。
2. 完整完成进阶任务：安全知识库、RAG、工具扩展和商用级约束。
3. 在不影响前两项的前提下完成挑战任务：SuperAgent 跨域调查与 ReAct 重规划。

内部硬截止为 2026-09-05。2026-08-25 前必须形成可完整演示的可用版本。

## 2. 成果定义

### 2.1 2026-08-25 可用版本

- Windows 原生方式可启动前端和后端。
- DeepSeek 可通过 OpenAI 兼容接口调用；无 Key 时自动切换 Mock LLM。
- 可从预置 Mock XDR 场景创建告警研判任务。
- 展示任务进度、风险评分、结构化结论、证据时间线和知识引用。
- RAG 支持混合检索、元数据过滤、重排和引用校验。
- 工具支持 allowlist、参数校验、dry-run、审批、幂等和模拟执行回查。
- 至少一条横向移动场景可升级到 SuperAgent，展示跨网络、端点、身份和知识的协同调查。
- 提供场景配置、工作流可视化、节点启停和一键运行等轻量低代码能力。
- 关键路径具备单元测试、契约测试和端到端测试。

### 2.2 2026-09-05 比赛交付版本

- Platform/Mock 双模式，其中 Mock 模式可作为稳定的离线演示预案。
- Docker Compose 部署文件和健康检查完整。
- 源代码、设计文档、开发文档、测试文档、总结报告齐全。
- 宣讲 PPT、3 分钟演示视频、90 秒精简演示路径齐全。
- 依赖扫描、密钥扫描、权限测试、Prompt Injection 测试和故障注入通过。
- 按 `trace_id` 可回放模型、检索、工具、审批、执行和错误事件。

## 3. 范围

### 3.1 必做

- 告警接入与标准化。
- 多源证据富化。
- 规则与 LLM 联合研判。
- 确定性风险评分。
- 安全知识库和 RAG。
- Tool Registry 与受控工具调用。
- dry-run、审批、执行、回查和审计。
- React 安全运营控制台。
- Mock XDR/Model/Response Adapter。
- 测试、文档、部署和 Demo。

### 3.2 冲刺

- SuperAgent Supervisor。
- 网络、端点、身份、知识、响应专门 Agent。
- 共享调查状态、冲突集和 Critic。
- ReAct 重规划、预算控制和停止条件。
- MCP 工具网关。
- 版本化安全 Skill 能力包。

### 3.3 非目标

- 自研网络流量采集器或检测引擎。
- 训练基础安全大模型。
- 完整复制深信服平台低代码引擎。
- 向模型开放任意 shell、SQL 或通用 HTTP 工具。
- 未审批的真实高风险处置。

## 4. 技术基线

| 领域 | 基线 |
|---|---|
| 后端 | Python 3.11、FastAPI、Pydantic |
| Agent | LangGraph；基础流程允许使用确定性状态图 |
| LLM | 统一 ModelAdapter；开发测试使用 DeepSeek |
| RAG | 关键词 + 向量混合检索、元数据过滤、重排、引用校验 |
| 数据 | SQLite（本地）/PostgreSQL（部署）；对象引用保存原始证据 |
| 向量索引 | Chroma（本地）；保持 Retriever 接口可替换 |
| 前端 | React、TypeScript、Vite、Ant Design |
| 工具 | Tool Registry；可选 MCP Gateway |
| 部署 | Windows 原生启动 + Docker Compose |
| 测试 | pytest、契约测试、固定回放数据集、前端类型检查 |

## 5. 数据与模型安全边界

- DeepSeek 仅处理合成数据或完成脱敏的数据。
- 真实 XDR 数据默认只进入深信服平台模型或获批准的本地模型。
- API Key 只从环境变量读取，不进入代码、Prompt、日志、测试快照或版本库。
- 高风险动作在真实环境中必须 dry-run、策略校验和人工审批。
- 合成数据使用保留测试网段、虚构账号和虚构资产，不使用真实组织信息。

## 6. 里程碑

### P0：契约与骨架（07-31 至 08-02）

- 初始化仓库、开发规范和启动说明。
- 冻结领域 Schema、状态枚举、错误模型和 Adapter 协议。
- 建立 Mock XDR 场景和测试夹具。
- 建立健康检查、场景列表和任务 API。

出口标准：项目可安装；最小 API 和领域测试通过。

### P1：告警研判最短闭环（08-03 至 08-07）

- 告警标准化、证据富化和确定性风险评分。
- DeepSeek/Mock LLM Adapter。
- 结构化研判输出和引用存在性校验。
- Job、Case、Trace、Checkpoint 和审计事件。
- 初版任务详情页面。

出口标准：预置告警可从接入运行到结构化结论。

### P2：进阶任务主体（08-08 至 08-14）

- ATT&CK、CWE/CAPEC、NVD/CISA 和法规快照构建脚本。
- 文档解析、分块、元数据、索引版本和删除传播。
- 混合检索、重排、上下文预算和引用校验。
- Tool Registry、查询工具、dry-run 和审批策略。
- Prompt Injection 与权限回归集。

出口标准：告警研判输出带可点击、可验证的知识引用；无越权工具调用。

### P3：受控响应与低代码展示（08-15 至 08-20）

- 动作计划、审批、幂等、模拟执行和回查。
- 场景配置表单、工作流视图、节点启停和版本。
- SSE 任务进度和 Trace 回放。
- Windows 一键启动与 Docker 构建文件。

出口标准：基础任务和进阶任务形成稳定的端到端闭环。

### P4：SuperAgent 冲刺与可用版（08-21 至 08-25）

- Supervisor、专门 Agent 和共享调查状态。
- 横向移动场景的并行调查、冲突校验和 Critic。
- 一次受控 ReAct 重规划。
- MCP 工具网关和 Skill 包最小实现。
- 完成 3 分钟主演示路径的首轮录屏。

出口标准：达到 08-25 可用版本验收基线。

### P5：平台联调准备（08-26 至 08-30）

- 根据平台资料补齐 XDR/Model/Response Adapter。
- 完成鉴权、字段、分页、限流、错误和 Webhook 映射。
- 运行 Mock 与 Platform 一致性契约测试。
- 提供真实环境敏感数据隔离策略。

出口标准：平台资料到位后可在 Adapter 层完成接入，不改业务 Agent。

### P6：加固与提交（08-31 至 09-04）

- 安全、性能、故障、恢复和对抗回归。
- 完成开发、测试、部署和总结文档。
- 完成 PPT、3 分钟视频、90 秒精简版和离线回放预案。
- 打包并执行最终提交清单。

出口标准：09-05 前提交完整作品。

## 7. 合成数据集

首版提供以下固定场景：

| ID | 场景 | 预期 |
|---|---|---|
| TRI-001 | 横向移动高危告警，证据完整 | 真阳性、高风险、生成动作计划 |
| TRI-002 | 合法业务扫描，存在白名单和变更单 | 误报、引用反证、不处置 |
| TRI-003 | 端点关键证据缺失 | 待确认、降低置信度、列出缺口 |
| TRI-004 | 重复 Webhook | 返回同一任务，不重复执行 |
| SUP-001 | 网络、端点和身份证据形成攻击链 | SuperAgent 协作并受控响应 |
| SUP-002 | 网络与身份结论冲突 | 保留冲突并补证或待确认 |
| ACT-001 | 未审批的高危动作 | 策略拒绝，副作用为零 |
| RES-001 | 工具超时后恢复 | 从检查点恢复，不重复写动作 |
| SEC-001 | 日志携带恶意提示 | 作为数据处理，不扩大权限 |

## 8. RAG 数据源规划

- MITRE ATT&CK STIX：行为、技术、战术和缓解措施。
- CAPEC/CWE：攻击模式和弱点分类。
- NVD CVE 与 CISA KEV：漏洞详情和已知在野利用优先级。
- 可信厂商安全公告：补充产品影响和修复建议。
- Sigma 规则与公开检测知识：补充检测语义。
- 中国官方网络安全、数据安全和个人信息保护法规。
- 后续平台接口、字段说明和处置手册。

仓库只保存许可允许、体积可控、可离线演示的筛选快照；完整数据由构建脚本下载。

## 9. MCP 与 Skill 设计

- 内部 Tool Registry 是核心执行入口。
- MCP Gateway 将符合安全策略的查询、检索和响应工具标准化暴露。
- MCP 故障不影响核心研判流程。
- Skill 是版本化的场景能力包，包含 Prompt、工作流、工具允许列表、知识范围、Schema、样例和评测。
- 首批 Skill：告警研判、横向移动调查、知识引用核验、受控响应。

## 10. 低代码能力

首版实现：

- 场景元数据与参数配置。
- 工作流节点和连接关系可视化。
- 节点启停、预算和超时配置。
- 模型、知识库和工具范围选择。
- 配置导入、导出、版本记录和一键运行。

完整拖拽式流程设计器不作为 08-25 阻塞项。

## 11. 验收指标

| 类别 | 指标 | 目标 |
|---|---|---|
| 研判 | 高危召回率 | 首轮标注后校准，目标不低于 95% |
| 输出 | 结构化输出成功率 | 不低于 99% |
| 证据 | 关键结论引用覆盖率 | 不低于 95% |
| RAG | Citation Precision | 不低于 95% |
| 安全 | 未授权高危动作 | 0 |
| 安全 | 跨租户数据泄漏 | 0 |
| 性能 | 告警研判 P95 | 目标不高于 20 秒 |
| 稳定性 | 主 Demo E2E | 100% |

## 12. 主要风险与预案

| 风险 | 预案 |
|---|---|
| 平台 API 延迟 | Mock 先行，Adapter 契约替换 |
| 平台模型能力或延迟不稳定 | 预热、超时、降级和固定回放 |
| 单人开发时间紧 | 先闭环后增强；非核心功能可拔插 |
| Docker 尚未安装 | Windows 原生启动；后续在 E 盘配置 Docker 数据 |
| 本机内存有限 | Docker 限 4GB；演示只启动必要服务 |
| 真实处置权限不足 | 测试资产、dry-run、审批和模拟回查 |
| 知识源更新或不可达 | 版本化离线快照和来源校验 |
| 对抗输入污染 | 分区 Prompt、Schema、allowlist 和持续红队集 |

## 13. Definition of Done

每项功能必须同时满足：

- 代码具备类型和输入校验。
- 正常、异常和安全边界测试通过。
- 模型、Prompt、Schema、知识索引和工具均有版本。
- 可通过 `trace_id` 复盘。
- 密钥与敏感数据不进入日志和版本库。
- Windows 原生模式可运行。
- 对应文档和演示说明同步更新。
