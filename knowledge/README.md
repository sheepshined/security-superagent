# 知识库

本目录用于保存经过筛选、许可允许且适合离线演示的安全知识快照。

来源登记在 `sources.json`，当前包括 MITRE ATT&CK Enterprise v19.1、2025 CWE
Top 25、CISA KEV、Sigma 横向移动核心规则，以及中国现行网络安全、数据安全、
个人信息保护、网络数据安全和关键信息基础设施保护法规。

完整原始数据、ONNX 模型和 Chroma 索引不进入 Git。索引器将来源缓存、许可、
抓取时间、SHA-256 和构建 Manifest 保存在 E 盘数据目录。`snapshots` 只保存经过
审核、可离线演示的最小回退语料；实时来源可用时，同源快照不会重复进入索引。

检索顺序固定为访问标签过滤、BM25/向量召回、RRF 合并、技术编号/来源/时效/
场景重排、文档去重和引用完整性校验。活动索引通过 `ACTIVE` 文件原子切换，构建
失败不会影响正在运行的后端。
