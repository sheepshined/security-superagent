# 演示脚本

## 3 分钟主演示

1. **0:00–0:20 登录与健康**：登录控制台，展示 DeepSeek、LangSmith、SQLite、
   Chroma、ONNX、Worker、MCP 状态，明确数据为合成 Mock XDR。
2. **0:20–0:45 配置**：打开固定安全拓扑，展示可配置 Agent、超时、预算、工具与
   知识范围；Critic、策略裁决和响应安全门不能关闭。
3. **0:45–1:35 SUP-001**：启动横向移动调查，SSE 高亮 Supervisor、Network、
   Endpoint、Identity、RAG、Critic 和裁决；展示攻击链证据、引用和 Agent 报告。
4. **1:35–2:20 受控响应**：提议隔离，执行 dry-run，展示计划哈希；切换独立审批员
   批准，执行 Mock 隔离并回查。强调未审批动作无法执行。
5. **2:20–2:45 Trace**：回放节点、工具、Observation、冲突、修订计划和终态，不展示
   隐藏思维链。
6. **2:45–3:00 安全收尾**：展示 30 条评测、50 条对抗样本、未授权高风险动作 0，
   说明模型故障会安全降级。

## 90 秒精简版

登录与健康 10 秒，SUP-001 实时调查 35 秒，审批与模拟隔离 25 秒，Trace 与评测
20 秒。删除配置细节，但保留“合成数据、四眼审批、安全降级”三项声明。

## 冲突场景 SUP-002

网络行为显示可疑 WinRM，身份/变更证据支持授权补丁。系统必须保留冲突、补充证据，
最终输出误报或待确认，不得生成高风险响应。该场景用于证明多 Agent 不是简单投票。

## 录屏前检查

- 管理员、分析员、审批员账号可登录，密码不出现在画面。
- DeepSeek 实时连通，LangSmith 项目可观察且仅含合成数据。
- 主流程连续运行 10 次；准备 Mock 回退但不得伪装为实时 DeepSeek。
- 浏览器缩放、时间、演示结论和引用文字完成用户确认。
- XDR 平台未通过契约测试时不替换 Mock 演示。
